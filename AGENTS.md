# Repository instructions

Follow CONTRIBUTING.md and component-specific licenses/instructions.

## User-required commit and push window

Before every `git commit` and every `git push`, check the current local date and
time. These operations are allowed only on weekdays at or after 22:00 or before
08:00, or at any time on Saturdays and Sundays. Use the machine's current local
timezone unless the user explicitly specifies another. Outside this window,
continue edits/builds/tests and leave changes uncommitted and unpushed. Do not
create an automation just to wait for the window. A newer explicit user
instruction may override this rule.
